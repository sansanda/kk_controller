## Lo útil de verdad
Markdown + Git funciona muy bien porque:

- es legible incluso sin renderizar
- diffs y revisiones son fáciles
- evita depender de Word o formatos binarios
- facilita documentación viva dentro del repositorio

## En resumen
Markdown es el formato del texto. Git es la herramienta que guarda y controla sus cambios.
